Bitcoin on Sequentia needs no bridge

Every Sequentia wallet holds and spends real bitcoin directly. It uses the same tb1… address for bitcoin and for Sequentia assets, so to use your bitcoin with Sequentia, send it to that address as it is. Nothing is wrapped.

SBTC is bitcoin pegged 1:1 on Sequentia, backed by BTC held in a reserve. It is only needed for:

  • confidential (blinded) transactions, which hide the amount on chain;
  • anything that needs a covenant, such as a limit order that rests on chain until it is filled.

If you need neither, you do not need SBTC. Wrapping moves your bitcoin into the operator's reserve until you unwrap it.

Compages is a proof-of-concept bridge into the Sequentia network, run by a single operator. It locks ether and ERC-20 tokens in a vault on Ethereum, SOL and SPL tokens with the operator on Solana, and bitcoin in an operator-held reserve for SBTC, and mints the matching asset on Sequentia. The operator performs every mint and release and holds every reserve, so using the bridge means trusting the operator. How each reserve is held is stated below; do not assume a threshold of signers where none is named.
